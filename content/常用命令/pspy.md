|                 |                             |                |
| --------------- | --------------------------- | -------------- |
| **监控定时任务（最常用）** | `./pspy64 -pf`              | 监控进程 + 文件系统事件  |
| 只看进程            | `./pspy64`                  | 只显示新进程         |
| 只看文件变化          | `./pspy64 -f`               | 只监控文件系统        |
| 缩短扫描间隔          | `./pspy64 -i 500`           | 每500毫秒扫一次（更敏感） |
| 输出到文件           | `./pspy64 -pf > output.txt` | 保存结果           |
