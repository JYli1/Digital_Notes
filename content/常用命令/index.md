# 常用命令

这里沉淀高频工具命令，目标是比赛或靶机时能快速复制、微调和回看用法。

## 扫描与枚举

- [[nmap]]：端口扫描、服务识别、脚本扫描。
- [[rustscan]]：快速端口发现。
- [[GitHacker]]：泄露 `.git` 目录时恢复源码。

## 爆破与凭据

- [[hydra]]：SSH、HTTP、FTP 等协议爆破。

## Shell 与提权

- [[反弹shell]]：各种反弹 shell 写法和稳定化。
- [[pspy]]：无 root 监控进程和计划任务。
- [[提权命令]]：Linux/Windows 提权枚举命令汇总。
