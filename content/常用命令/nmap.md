## 扫端口
nmap -p- 10.241.108.244   `全端口扫描`
nmap -sn  10.241.108.0/24 `扫同网段存货主机`

| 参数      | 作用           | 一句话记忆           |
| ------- | ------------ | --------------- |
| `-sn`   | Ping扫描，找存活主机 | **只查在线，不扫端口**   |
| `-sS`   | TCP半开扫描（默认）  | **快速隐蔽，首选扫描**   |
| `-sV`   | 探测服务版本       | **知道是什么软件+版本号** |
| `-O`    | 探测操作系统       | **猜对方是什么系统**    |
| `-p`    | 指定端口         | **扫哪个端口**       |
| `-T0~5` | 速度控制         | **数字越大越快**      |
|         |              |                 |
|         |              |                 |
