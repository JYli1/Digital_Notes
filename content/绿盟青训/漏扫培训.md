# 漏扫安装
## 虚拟机创建
1. FTP获取.iso文件
2. 新建虚拟机
3. Workstation 16.2.x
4. 选镜像
5. Linux / 其他 Linux 2.6.x 内核 64 位
6. CPU最低配置
![](file-20261027212615475.png)
7. 存储最低配置 ![](file-20261027212639261.png)
8. 选桥接
9. 进入选择 I/O 控制器类型页签，选择【LSI Logic】
10. 进入选择磁盘类型页签，选择【SCSI（S）（推荐）】
11. 进入选择磁盘页签，选择【创建新虚拟磁盘】
12. 进入指定磁盘容量页签，配置磁盘大小，选择【将虚拟磁盘拆分成多个文件】最大磁盘大小 300G（非最低）
完成
## 安装系统
1. 开启，全部默认，管理口手动配置
默认只有一个网络配置器，是管理口的，我们需要添加一个扫描口，所以再加一个网络配置器（NAT即可，因为要扫其他虚拟机，都用NAT）
扫描口桥接好点

2. （初始为 conadmin 和 conadmin）
3. 选择菜单 Network Settings > Set Scaning Interface > Set Scan Interface 1。
4. 管理口ip自动配好了

## 加密狗
1. 插上加密狗
2. 虚拟机 > 可移动设备 > Philips USB 输入设备 > 连接
3. 虚拟机 > 可移动设备 > Philips USB 输入设备 > 在状态栏中显示
4. 导入证书（在申请记录里面下载）
5. 用https://管理口ip 登录
6. 选加密狗认证
7. 上传上去认证即可
